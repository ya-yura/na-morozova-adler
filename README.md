# Гостевой дом «На Морозова»

Production-ready адаптивный лендинг для гостевого дома в Адлере. Сайт собирает даты, состав гостей и пожелания, предлагает подходящие категории номеров и формирует структурированный запрос для WhatsApp.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Production-проверка:

```bash
npm run build
npm run lint
```

## Что внутри

- `app/page.tsx` — лендинг, подбор номера, рекомендации, WhatsApp-запрос, мобильная панель действий.
- `app/content.ts` — единая структура редактируемого контента: номера, цены, даты актуализации, условия, галереи и ссылки.
- `app/globals.css` — адаптивная стилизация, доступные состояния фокуса и `prefers-reduced-motion`.
- `public/images/` — реальные фотографии объекта, загруженные из карточки на «Куда на море.ру».

## Источники и актуализация

Данные проверены 20 августа 2026 года по следующим источникам:

- [Яндекс Карты](https://yandex.ru/maps/org/gostevoy_dom_na_morozova/1139483108/) — адрес, телефон, рейтинг 4,6 и 216 оценок, часть характеристик и отзывы.
- [Официальный каталог](https://gostevoj-dom-na-morozova.clients.site/) — карточки номеров, характеристики и цены, где они опубликованы.
- [Куда на море.ру](https://www.kudanamore.ru/adler/hotels/40475/) — варианты размещения, площади, правила, ориентир 5–7 минут до моря, отзывы и фотографии.

Цены в интерфейсе показаны только из официального каталога: 3 500 ₽ для 2-местного с балконом и 3-местного, 4 000 ₽ для стандартного 4-местного, 5 000 ₽ для 5-местной студии. Для категорий, где цена не подтверждена в выбранном источнике, сайт показывает «Уточняется», чтобы не смешивать расхожие цены разных каталогов. Наличие не подключено к системе бронирования и всегда обозначено как уточняемое.

Telegram не добавлен: подтверждённой ссылки владельца в исходных материалах нет. Отдельные фотографии санузлов не выделены в доступной галерее и не заменены стоковыми изображениями.
